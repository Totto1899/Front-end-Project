# Front-end-Project

E-Commerce para el alquiler de películas.

En este proyecto se desarrolló una página web para el alquiler de películas de todos los géneros, utilizando HTML, CSS y JavaScript. El objetivo principal es poner en práctica los conocimientos adquiridos en el curso de Front-End, construyendo una interfaz interactiva y funcional.

## Características principales

- Maquetación y diseño de múltiples páginas.
- Filtrado dinámico de películas por categoría.
- Sistema de carrito de compras interactivo.
- Persistencia de datos y sesión de usuario mediante almacenamiento local.
